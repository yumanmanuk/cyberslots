# Diff 命令（/diff）

> 在 TUI 内交互式查看和审阅工作区改动、提交历史和 agent 回合 diff。

## 概述

`/diff` 命令打开交互式 Diff 查看器——一个全屏面板，让你检查工作区和对话历史中的改动。它支持三种独立模式（VCS、Turn、Commit），并提供交互式审阅工作流，你可以逐行添加评论来引导 agent 的下一步。

## 交互式 Diff 查看器面板

打开 Diff 查看器：

1. 在 prompt 框输入 `/diff`。
2. 按 `Enter`。

```text
/diff
```

## 导航与控制

Diff 查看器有三种模式，用 `Tab`（或 `→` / `←` 方向键）循环切换：

- **VCS 模式**：显示当前工作区所有已修改和未跟踪文件的列表。
  - 自动支持 Git、Mercurial（Hg）和 Jujutsu（JJ）。
  - 用 `↑ ↓` 导航文件列表，`Enter` 打开详情视图。
- **Turn 模式**：显示 agent 在当前对话每个回合引入的改动。
  - 便于逐步审阅 agent 的工作。
  - 用 `↑ ↓` 导航，`Enter` 查看详情。
- **Commit 模式**：渲染仓库的交互式提交图/树。
  - 用 `↑ ↓` 导航提交链。
  - 用 `← →` 导航图中相邻分支。
  - 按 `Enter` 加载所选提交的 diff。

## 逐步演练

以下是如何用 Diff 查看器审阅改动、添加评论、引导 agent。

### 1. 审阅工作区改动（VCS 模式）

运行 `/diff` 时，若有未提交改动，默认以 VCS 模式打开。你会看到已修改和未跟踪文件的列表。

在文件上按 `Enter` 打开其详情视图，显示统一 diff。

- 用 `↑ ↓`（方向键）滚动 diff。
- 用 `j`/`k`（或 `↑ ↓`）在文件间快速切换，无需返回列表。
- 用 `n`/`N` 跳到下一个/上一个 diff hunk。

### 2. 添加评论、引导 agent

在详情视图中，你可以审阅代码并把反馈直接写到特定行上。

- **第 1 步：定位行** — 滚动到你想评论的行。
- **第 2 步：打开评论输入** — 按 `c`，评论输入浮层在底部打开。
- **第 3 步：写反馈** — 输入反馈并按 `Enter` 保存（或 `Esc` 取消）。
- **第 4 步：管理评论** — 已保存评论在 diff 中被标记。可高亮该行按 `d` 删除评论。
- **第 5 步：退出并提交** — 按 `Esc` 返回文件列表。再按 `Esc` 退出 `/diff`。若有未保存评论，出现确认屏：
  - 按 `Shift+Y` 批准并退出。你的评论被格式化并作为下一条 prompt 发给 agent，让你引导它的下一回合。
  - 按 `Shift+N` 拒绝并退出，丢弃评论。

### 3. 审阅回合历史（Turn 模式）

按 `Tab` 切到 Turn 模式。这按引入改动的对话回合分组，让你精确看到 agent 在之前各步做了什么。

### 4. 导航提交树（Commit 模式）

再按 `Tab` 切到 Commit 模式。这把仓库提交历史渲染为交互式图。你可以上下导航提交链，或用 `← →` 在分支间跳转。

高亮任一提交按 `Enter` 加载并审阅其 diff。

## 键盘快捷键参考

### 文件列表视图（VCS 与 Turn 模式）

| 键 | 动作 |
|---|---|
| `Tab` / `→` / `←` | 循环模式（VCS → Turn → Commit） |
| `↑` / `↓`（或 `j`/`k`） | 导航文件列表 |
| `Enter` | 打开所选文件的详情视图 |
| `Esc` | 退出 Diff 查看器 |

### 文件详情视图

| 键 | 动作 |
|---|---|
| `↑` / `↓` | 滚动 diff 内容 |
| `PgUp` / `PgDn` | 按页滚动 diff |
| `j` / `k`（或 `↑` / `↓`） | 切换到下一个/上一个文件 |
| `n` / `N`（或 `shift+n`） | 跳到下一个/上一个 diff hunk |
| `c` | 在当前行添加/编辑评论 |
| `d` | 删除当前行的评论 |
| `Esc` | 返回文件列表视图 |

### 提交树视图（Commit 模式）

| 键 | 动作 |
|---|---|
| `↑` / `↓` | 导航提交历史 |
| `←` / `→` | 导航图中相邻分支 |
| `Enter` | 加载所选提交的 diff |
| `Esc` | 退出 Diff 查看器 |

### 退出确认屏

| 键 | 动作 |
|---|---|
| `Shift+Y` | 退出并把评论发给 agent |
| `Shift+N` | 退出并丢弃评论 |
| `Esc` | 返回文件列表视图 |
